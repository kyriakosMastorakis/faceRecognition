Face Detection Webcam App

A simple real-time face detection application built with Python and OpenCV.
The program uses your webcam to detect faces and draw colored rectangles around them using Haar Cascade face detection.

Features
Real-time webcam face detection
Displays the number of detected faces
Change rectangle colors with keyboard shortcuts
Save screenshots instantly
Beginner-friendly OpenCV project
Requirements

Install OpenCV before running the program:
pip install opencv-python
python main.py
| Key   | Function         |
| ----- | ---------------- |
| ESC   | Exit program     |
| R     | Red rectangle    |
| B     | Blue rectangle   |
| G     | Green rectangle  |
| Y     | Yellow rectangle |
| P     | Purple rectangle |
| SPACE | Save screenshot  |

Technologies Used
Python
OpenCV
Haar Cascade Classifier
Description

This project captures live video from the webcam and processes each frame to detect faces.
Detected faces are highlighted with customizable colored rectangles, and users can save snapshots during execution.
It is a great beginner project for learning basic computer vision with OpenCV.
